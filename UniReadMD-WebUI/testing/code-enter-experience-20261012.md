# 代码块源码与正文回车体验修复

日期：2026-10-12。版本：1.1.0。

## 修复内容

- 代码块进入源码编辑后保留背景、圆角、边距和等宽字体。
- 已支持的代码语言保留语法高亮，围栏标记使用次要文字颜色。
- 长代码行使用横向滚动，高亮层与输入层同步，不通过自动折行撑高代码块。
- 代码容器整体参与源码映射，点击背景留白和代码文字均可正确定位。
- 中文组合输入期间显示原生文字，结束后恢复高亮；未知语言安全回退。
- 按用户确认的行为，正文 Enter 进入下一条空白行，光标在行首。
- 排除浏览器末尾光标占位产生的额外换行，连续回车逐次增加一行。
- 正文备用源码编辑也使用单换行；标题换段、列表续项和表格导航继续保留。
- 退格合并正文两行时划分撤销边界，避免撤销连带删除此前输入的文字。

本次属于现有编辑行为的缺陷修复，按 OpenSpec 的缺陷修复例外直接实施。
代码样式只读参考本机 Typora 的 github.css；未进行 Typora 界面自动操作对照。
