# 表格原位编辑与右键菜单优化记录

## 修复内容

普通表格单元格单击后直接在原单元格中编辑，不再覆盖独立输入框。进入编辑时保留加粗、
链接、字号、行高、列对齐和位置；CodeMirror 继续作为唯一源码，保存及导出前提交活动编辑。
Tab、Shift+Tab、Enter 和既有行列快捷键继续有效，Shift+Enter 保留单元格内换行。
中文组合输入期间不导航，撤销、重做及 Escape 撤回继续有效。

含图片、数学公式或不支持的 HTML 的复杂单元格仍保留源码输入入口；Alt 单击可主动使用
该入口。无属性的 `<br>` 换行可以重新进入原位编辑，不会因保存而退回独立输入框。

工作区插入、表格、图片比例、文件及源码备用菜单共享紧凑样式：224px 宽、13px 字号、
6px 圆角、轻阴影、分隔线和深浅主题。菜单先隐藏测量实际尺寸，再限制到可用区域，
减少错误上移、跳位和边缘裁剪。保留图片比例及已有菜单命令。
编辑后立即右键会先提交单元格，待预览刷新完成后设置选区并显示菜单，避免菜单消失或
行列操作丢失尚未提交的内容。
