# UniReadMD 1.1.0 实现与验证记录

## 功能范围

- 普通点击正文、标题、简单列表项和引用后直接在原样式中编辑，不展开 Markdown 文本框。
- 编辑期间保留活动 DOM 和浏览器选区，输入经 CodeMirror 事务写回唯一 Markdown 数据源。
- 支持中文组合事件、换段、列表续项与退出、引用续行、段首退格合并、相邻块移动。
- 支持加粗、斜体、链接、安全格式粘贴、撤销重做、保存及离线 HTML 导出。
- 保存、导出和切换模式先提交编辑；文档替换结束旧会话，避免旧块写入新文档。
- Alt＋单击保留 Markdown 片段精确编辑。图片、公式、代码、嵌套列表等复杂块保留既有入口。
- 图片右键支持常用比例、自定义 1%～400% 和恢复自动，以原图尺寸为基准保持纵横比。
- 图片修改只作用于选中目标，保留外层链接、标题和引用定义，支持保存、撤销和导出。
- 顶部快捷操作栏及左下偏好设置默认隐藏，原生视图菜单可独立切换并跨重启保存。
- 源码开关采用可取消的圆形选择外观；侧栏开关在源码与渲染模式中始终可用。
- 工作区右键可插入标题、表格、图片、段落、代码、公式、引用、列表、任务和分割线。
- 应用与前端版本统一为 1.1.0，主程序 Windows 文件及产品资源版本为 1.1.0.0。

## 回归中发现并修复的问题

1. 冻结预览期间，撤销回原文可能使绑定 HTML 字符串相同；加入渲染修订标记确保清除旧 DOM。
2. 单行 Markdown 图片转为 HTML 后可能吞掉下一行 Markdown；必要时补充块间空行。
3. 空文档的 `---` 分割线会被前置信息插件识别；插入采用等价的 `***`。
4. 正文输入尚未防抖提交时立即右键，会被延后的源码监视回调关闭新菜单；改为同步关闭旧目标。
5. 自动滚入新表格会触发既有滚动关闭编辑逻辑；待定位滚动完成，再直接打开首个单元格编辑器。
6. Windows 批处理内联 Node 表达式触发 CMD 括号解析；改用独立版本读取脚本并实测资源修改。
