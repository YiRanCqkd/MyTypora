# UniReadMD 设计系统

## 1. 氛围与识别

UniReadMD 是克制、紧凑的 Windows 桌面 Markdown 工作台。界面以 Typora 式文档画布为中心，
用浅灰侧栏、低对比度分隔线和窄状态栏承载工具，不与正文争夺注意力。产品的识别特征是
'固定大纲与纯净纸面'：导航始终贴近内容，同时预览区保持接近纸张的连续阅读体验。

本文件只提取 `frontend/src/styles.css` 与 `frontend/src/App.vue` 中已经存在的视觉规则。
Task 2 不新增品牌方向，不改变布局、样式值或产品文案。

## 3. 字体排印

### 字体栈

- 界面与正文：`'Segoe UI', 'PingFang SC', sans-serif`。
- 标题栏与状态栏：`Verdana, sans-serif`。
- 源码与代码：`'Consolas', 'Microsoft YaHei UI', monospace`。

### 现有字号层级

| 层级 | 大小 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| 文档 H1 | `2.25em` | `700` | `1.2` | 一级标题 |
| 文档 H2 | `1.75em` | `700` | `1.225` | 二级标题 |
| 文档 H3 | `1.5em` | `700` | `1.43` | 三级标题 |
| 文档 H4 | `1.25em` | `700` | `1.4` | 四级标题 |
| 文档 H5/H6 | `1em` | `700` | `1.4` | 五、六级标题 |
| 文档正文 | `15px × --content-zoom` | `400` | `1.6` | Markdown 预览 |
| 面板正文 | `14px` | `400` | `1.35` | 侧栏面板 |
| 文件与大纲 | `12px` 至 `16px` | `400` 至 `700` | `1.45` | 树、搜索与标题层级 |
| 控件与状态 | `12px` | `400` | 控件相关 | 标题栏、按钮与状态栏 |
| 元数据 | `11px` | `400` | 控件相关 | 路径、统计和字典状态 |

### 规则

- 内容缩放通过 `--content-zoom` 影响预览字号，并保持源码编辑器字号联动。
- 中文优先由系统中文字体回退，代码区使用微软雅黑 UI 回退避免 CJK 缺字。
- 源码模式标题按正文等宽层级显示；渲染模式恢复文档标题层级。

## 4. 间距与布局

### 基准与常用间距

现有界面以约 `4px` 为节奏基准，同时保留桌面工具栏所需的 `2px`、`6px`、`10px` 和
`14px` 紧凑间距。常用值如下：

| 角色 | 值 | 现有用途 |
| --- | --- | --- |
| 极紧凑 | `2px` | 状态项、菜单内部间隔 |
| 紧凑 | `4px` | 按钮内边距、列表间距 |
| 控件间距 | `6px` 至 `8px` | 工具组、浮层内容 |
| 面板间距 | `10px` 至 `12px` | 侧栏、表格和代码块 |
| 内容间距 | `16px` 至 `24px` | 文档元素与窄屏边距 |
| 文档侧边距 | `48px` | 默认预览和源码画布 |
| 文档底部留白 | `60px` 至 `100px` | 连续阅读与滚动空间 |

### 结构

- 应用高度使用 `100dvh`，并保留 `100vh` 兼容声明。
- 标题栏高 `28px`，状态栏高 `30px`，中间工作区占满剩余空间。
- 默认侧栏令牌为 `270px`，运行时初始宽度为 `300px`，可拖拽并持久化。
- 内容最大宽度令牌为 `1100px`；`1400px` 以上扩到 `1200px`，`1800px` 以上扩到
  `1320px`。
- `1080px` 以下侧栏宽度改为 `240px`，内容侧边距改为 `24px`。
- Source 与 Render 为互斥单列视图，不在 Task 2 改为分栏或重排信息架构。

### 已知现状偏差

- 个别几何值不是 `4px` 的整数倍，用于像素级边框、光标和紧凑桌面控件。
- 侧栏 CSS 默认值与运行时默认值不同；Task 2 记录但不修正，以避免视觉回归。

## 5. 组件

### 标题栏与窗口按钮

- 结构：左侧菜单与文档名、可拖拽中区、右侧最小化/最大化/关闭按钮。
- 状态：普通、悬停；关闭按钮悬停使用红色危险状态。
- 尺寸：标题栏 `28px`，窗口按钮宽 `46px`。

### 文件与大纲侧栏

- 结构：搜索框、文件/大纲标签、可滚动树或标题列表、底部留白。
- 状态：悬停、活动、展开、折叠、空结果；活动文件使用表面令牌而非品牌填充。
- 交互：侧栏可隐藏、拖拽调整宽度，并在刷新后恢复。

### 文档画布

- 结构：互斥的 Markdown 预览与 CodeMirror Source 编辑器。
- 内容：标题、段落、列表、引用、表格、代码、脚注、任务列表和图表。
- 状态：默认、Source、Focus、Typewriter、搜索高亮、加载、拖放。

### 浮层编辑器与菜单

- 结构：块编辑透明文本区、表格单元格编辑框、表格菜单和源码菜单。
- 表面：编辑浮层延续文档字体；菜单使用主表面、边界和轻阴影。
- 状态：焦点、悬停、提交、取消；Esc 关闭或回滚当前交互。

### 状态栏与拼写面板

- 结构：左侧侧栏/Source 切换，右侧缩放、字数、阅读时间、字符和行号。
- Source 模式隐藏非必要统计，拼写面板从状态栏上方弹出。

## 6. 动效与交互

### 现有时序

| 类型 | 时长 | 缓动 | 现有用途 |
| --- | --- | --- | --- |
| 布局切换 | `200ms` | `ease` | 侧栏、标题栏、状态栏和内容宽度 |
| 光标闪烁 | `1.06s` | `steps(1)` | Source 模式活动光标 |
| 即时反馈 | 无显式动画 | 不适用 | 按钮、文件树和菜单悬停 |

### 交互规则

- Source、Focus、Typewriter、侧栏和搜索状态通过稳定 class 映射到样式。
- 编辑、表格、搜索和菜单均保留键盘入口与 Esc 退出路径。
- 现有布局切换会动画 `margin-left`、`width` 和网格列，属于提取到的现状；Task 2
  不调整动效实现。
- 当前样式尚未集中声明 `prefers-reduced-motion`，由后续可访问性任务处理。

## 7. 深度与表面

现有策略是克制的混合深度：主工作区依靠色调变化和 `1px` 边界分层，只有搜索面板、菜单、
拼写面板、加载卡片和拖放提示等临时浮层使用阴影。普通文件项、面板和正文不使用卡片化阴影。

| 层级 | 现有处理 | 用途 |
| --- | --- | --- |
| 基础 | 相邻表面色调变化 | 页面、侧栏与文档画布 |
| 分隔 | `1px solid var(--line)` | 标题栏、状态栏、输入和表格 |
| 轻浮层 | `0 6px 16px rgba(0, 0, 0, 0.16/0.18)` | 单元格编辑器与拼写面板 |
| 菜单 | `0 10px 22px rgba(0, 0, 0, 0.2)` | 表格与源码上下文菜单 |
| 强提示 | `0 8px 24px rgba(0, 0, 0, 0.16)` | 文件拖放提示 |

所有 Task 2 拆分模块继续复用这些现有 class、令牌和 DOM 结构，不增加新的视觉层级。
