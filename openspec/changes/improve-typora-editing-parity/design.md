# 设计

## 授权与实施顺序
用户的“按建议顺序修复，向 typora 靠齐”批准了上一轮明确列出的五项优先任务。
依次实施和验证，无需重复请求提案批准。

## 内容与安全
表格分隔符作为可选元数据保存，兼容旧的 header/rows 模型。剪贴板 HTML 仅解析安全
结构为 Markdown，不执行脚本、读取文件或自动下载资源。预览文本偏移由 Markdown
语法解析确定，不能用渲染字符数直接代替源码字符数。文件迁移仅重写实际图片引用，
不修改代码示例；失败时保留源文档。高级导出采用固定参数及受授权的参考文档。

## 验收
包含转义竖线与代码片段的表格编辑后列数和对齐保持正确；网页粘贴保留标题、列表、
链接、表格及代码；复制提供 HTML 和 Markdown 纯文本；格式内容光标映射与跨块选区
正确；跨目录移动和另存为保持图片可定位；导出选项经过主进程验证并兼容旧设置。
