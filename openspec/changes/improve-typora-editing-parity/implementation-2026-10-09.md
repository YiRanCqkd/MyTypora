## 本轮完成范围

按用户确认的建议顺序，完成五项增量改进。继续以 CodeMirror 中的 Markdown
作为唯一正文来源，兼容既有设置与 IPC 调用，不改变原生路径授权规则。

| 顺序 | 改进 | 结果 |
| --- | --- | --- |
| 1 | 表格保真 | 保留列对齐和转义竖线，列增删与移动同步对齐信息，新增列对齐菜单 |
| 2 | 富文本剪贴板 | 安全 HTML 转 Markdown，复制同时提供 Markdown 和 HTML，保留纯文本粘贴 |
| 3 | 光标与实时编辑 | 语法树映射常见内联格式，输入保持光标，保留跨块选区并支持分段格式操作 |
| 4 | 图片引用联动 | 跨目录移动和另存为复制相对图片，更新普通及引用式图片，保留源文档资源 |
| 5 | 高级导出 | 独立 PDF 边距、自定义纸张、主题及分页、图片尺寸与质量、参考文档和元数据 |

表格分列按反斜线奇偶判断竖线是否转义，序列化不会重复转义已有内容。
图片迁移以实际 Markdown 图片语法定位引用，不改写代码示例；失败清理仅涉及本次
创建的目标资源目录。保存期间继续输入时，保留新输入及未保存状态。

富文本粘贴保留标题、常见内联格式、链接、图片、表格、嵌套列表、引用和代码，
过滤危险链接。使用 Ctrl+Shift+V 可直接粘贴纯文本。

导出设置采用白名单和固定转换参数，Word 参考文件及 EPUB 封面通过原生对话框授权。
参考文件路径仅在本次应用会话中复用，重启后重新选择，避免持久化设置扩大权限。
自定义 PDF 纸张和边距按英寸传给打印接口，依据
[Electron 打印接口文档](https://www.electronjs.org/docs/latest/api/web-contents/)。

## 仍与 Typora 存在的差异

- 编辑仍采用块级文本适配层，尚未实现逐内联片段原地展开编辑。
  公式等复杂渲染节点的点击与源码映射仍存在边界。
- 已处理 HTML 剪贴板，尚未实现仅含 RTF 格式的原生富文本剪贴板转换。
- 图片联动覆盖相对 Markdown 图片；目录整体移动、原始 HTML 图片标签、
  跨工作区绝对路径图片、批量图片管理及上传尚未完整实现。
- 导出增加了常用设置，尚未提供完整模板体系、自定义 Pandoc 命令及幻灯片流程。
- 前轮记录的选区字数统计、图表密集文档懒渲染、页面内复杂正则阻塞等问题仍待完善。
- 原生 Electron 和 Pandoc 验收、安装卸载验证、全工程覆盖率及旧解析性能门槛未完成。

本轮属于五项优先任务的增量靠齐，不能认定已具备标准 Typora 的全部能力。
完整原生验收和实际部署未完成，OpenSpec 保留在 changes 下，不提前归档。
