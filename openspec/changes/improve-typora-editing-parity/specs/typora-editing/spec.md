## ADDED Requirements

### Requirement: 表格与剪贴板保真
系统 SHALL 保留表格列对齐和转义竖线，提供安全富文本粘贴与带格式复制。

#### Scenario: 编辑带对齐和转义内容的表格
- **WHEN** 用户修改单元格或移动列
- **THEN** 列数、列对齐和其他单元格内容保持正确

#### Scenario: 粘贴网页内容
- **WHEN** 剪贴板包含 HTML 标题、列表、链接、代码和表格
- **THEN** 转换为 Markdown，危险协议与脚本不进入可执行内容

### Requirement: 编辑光标与图片引用联动
系统 SHALL 准确映射常用内联格式中的光标，并在移动或另存为时保持相对图片可定位。

#### Scenario: 点击加粗文本
- **WHEN** 用户在预览的加粗或链接文字中点击
- **THEN** 编辑光标落在对应的 Markdown 内容位置，而非格式标记或链接地址

#### Scenario: 文档跨目录移动
- **WHEN** 用户移动含相对图片的 Markdown 文档
- **THEN** 图片引用按新目录重定位，未保存内容不被磁盘旧版本覆盖

### Requirement: 可配置高级导出
系统 SHALL 提供经过验证的纸张、独立页边距、图片尺寸质量和文档元数据配置。

#### Scenario: 旧 PDF 设置继续可用
- **WHEN** 用户沿用仅含统一页边距的旧设置
- **THEN** 导出保持原有默认行为

#### Scenario: 无效导出选项
- **WHEN** 页面提交越界尺寸或未授权参考文档
- **THEN** 主进程拒绝该配置且不写出半成品
