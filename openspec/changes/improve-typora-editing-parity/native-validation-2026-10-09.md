# 限制解除后的原生验证

## 范围与环境

验证 Windows x64 的 NSIS 安装包及安装后的真实 Electron 程序。
所有测试文档、图片和应用用户数据使用独立目录，原有全局安装不覆盖。
安装使用 `/currentuser` 和独立 `/D` 目录，卸载只针对测试副本。

转换使用已有官方便携 Pandoc 3.10，仅向测试进程添加临时 PATH，未修改系统 PATH。
运行测试保留真实沙箱、IPC、路径授权、文件系统、Chromium 打印和 Pandoc 子进程。
自动化文件选择通过测试脚本替换对话框返回值，不能视为原生文件对话框的人工验收。

## 原生验证发现的缺陷

旧安装包的“粘贴截图”在真实系统剪贴板下返回：

```text
Error invoking remote method 'image:paste': TypeError: clipboard.readImage is not a function
```

本地 Electron 44.7.0 类型声明及
[官方剪贴板文档](https://www.electronjs.org/docs/latest/api/clipboard)
确认当前接口使用异步 `read()` 和 `ClipboardItem.getType()`。
已修复图片读取，保留旧同步接口兼容，读取字节前继续检查 20 MiB 上限。
同时处理文件菜单异步写入剪贴板失败，避免出现未处理的 Promise 拒绝。

增加四项回归，主进程测试共 50 项通过。实际系统 HTML 粘贴与双格式复制在旧包中
已通过，截图粘贴在旧包中失败。修正版三个系统剪贴板检查均通过，并还原原剪贴板。

原有原生测试脚本还有 Windows 自动化假设问题：CDP 键盘输入不稳定触发菜单加速键，
而原生模式会隐藏网页标题栏。改为调用真实菜单入口并检查修改标记是否存在。
等待测试进程退出后再清理临时目录，避免清理时的文件锁错误掩盖功能断言失败。
