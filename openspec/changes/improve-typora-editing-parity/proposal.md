# 改善 Typora 编辑与导出兼容性

## Why
用户已审阅剩余功能差异，并要求按建议顺序修复。本提案记录该已授权范围，
依次处理表格保真、富文本剪贴板、预览光标、图片引用联动和高级导出配置。

## What Changes
- 保留表格列对齐，正确识别转义竖线，结构操作同步列元数据。
- 增加安全 HTML 转 Markdown、带格式复制和纯文本粘贴回退。
- 通过 Markdown 语法树映射预览文本光标，保留用户跨块选区。
- 文档移动和另存为时重定位相对图片引用，保持未保存内容。
- 增加独立 PDF 页边距、自定义纸张、标题分页、图片导出尺寸和质量、
  Word 参考文档及 EPUB 元数据配置，所有文件选取维持原生授权。

## Impact
- 影响 editor、workspace、export 及 Electron 文件服务。
- 保持旧设置和 IPC 参数兼容，继续以 CodeMirror 为唯一 Markdown 数据源。
- 不引入新的富文本内核，不开放任意命令执行或绕过路径授权。
- 原生运行验收和实际部署完成后再归档，未完成的验收如实记录。
