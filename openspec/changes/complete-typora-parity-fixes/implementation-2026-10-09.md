## 性能

全文搜索达到结果上限后停止扫描，大纲与滚动锚点使用二分查找。
源码模式跳过隐藏预览的搜索标记，字数统计复用最后一次解析结果。

旧 Node 基准实际调用工程中的查找工具，不再重复实现测试算法。
本轮五 MiB 基准搜索为 5.79 ms，大纲滚动模拟为 0.24 ms，均优于原基线。
纯 Markdown 解析为 1549.82 ms，原基线为 835.32 ms，性能检查仍明确失败。
未更新基线，也未使用 PERF_APPROVE 放行。

真实页面 6,575,016 字节文档的打开、编辑、完整搜索和滚动用例通过。
打开约 6.25 秒，全文搜索 374 ms，尾部编辑并更新预览约 2.32 秒。
最终打开、编辑和搜索测量保存在发布验证目录的 browser-performance.json。
该语料为长正文，不能据此认定大量公式、图表或图片文档也满足相同耗时。

## 仍存在的边界

- 编辑仍使用源码块适配层，复杂嵌套内联格式的点击光标偏移仍为估算，未替换成完整富文本内核。
- 正则文档搜索在页面线程执行，复杂回溯表达式仍有阻塞风险；跨文件搜索已使用可终止线程。
- 未实现跨卷目录移动与目录复制；失败保留原目录。移动文档不自动重写全部相对资源链接。
- 尚未增加选区字数统计和图表密集文档的懒渲染。
- Word、ODT、RTF、EPUB、LaTeX 导出和外部格式导入仍依赖 Pandoc 3.10。
- 当前环境阻断原生程序及转换子进程验收，全量覆盖率和旧解析性能门槛仍待完成。

因此本轮属于缺陷修复及主要功能补齐，不能宣称已经完全达到标准 Typora 的全部能力。
用户尚未部署本次产物，OpenSpec 保留在 changes 下。
