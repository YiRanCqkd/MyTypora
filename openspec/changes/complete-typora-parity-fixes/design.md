# 设计

## 实施授权
本变更对应用户已审阅的检查结果及其“修复以上内容”指令，不重复请求提案审批。

## 数据与安全边界
- CodeMirror 文档保存原始 Markdown，渲染 DOM 不反向序列化为文档。
- 任务状态仅依据解析器提供的源行号修改，不按全文正则匹配序号推断。
- 本地链接从已授权源文档解析；新图片和文件通过原生对话框或受信任拖放获取。
- preload 在隔离上下文校验真实拖放事件；页面合成事件不能申请新路径权限。
- 图片根目录只能来自已授权工作区或用户原生目录选择，front matter 不能自行授权。
- 重命名、移动和删除校验真实路径、目标父目录与扩展名，不跟随目录联接越界。

## 编辑与渲染
- 使用现有块源映射保持原地编辑，增加块之间的键盘流和光标落点。
- 标题生成稳定唯一锚点，内部链接按锚点查找，无匹配时显示明确提示。
- 源码编辑继续使用 CodeMirror；预览高亮注册常用语言，未知语言按安全纯文本显示。
- 搜索使用 Unicode 边界和明确的正则开关；字面替换不解释美元特殊序列。
- 专注模式在预览标记活动块，打字机模式滚动当前实际编辑位置。

## 持久化与导出
- 会话写入保留一个统一防抖入口，关键操作强制 flush；草稿按内容变化保存历史。
- 恢复列表返回元数据，用户选中后再加载内容，不一次向页面复制全部历史正文。
- PDF 配置经过主进程字段白名单与范围校验，保留默认导出兼容。
- Pandoc 固定版本仍为 3.10；缺少依赖时禁用相关入口并说明安装条件。

## 验证
先保留现有失败复现记录，再添加对应单元和端到端断言并执行修复后的验证。
覆盖率报告区分完整工程和核心子集；性能测试包含真实页面的打开、编辑及搜索。
