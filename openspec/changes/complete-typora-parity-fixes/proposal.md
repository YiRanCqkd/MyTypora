# 补齐 Typora 对比检查发现的问题

## Why
2026-10-08 的对比检查复现了任务列表误改、图片导出授权变化、搜索替换、快照频率、
内部链接和中文统计问题，同时发现图片、工作区、恢复及导出配置缺少完整操作入口。
用户于 2026-10-09 明确要求修复上述全部内容，本提案记录该已授权范围及验收标准。

## What Changes
- 按 Markdown 源映射修改任务状态，统一图片预览和导出资源能力。
- 补齐 Unicode、正则和完整结果导航，统一逐项与批量替换语义。
- 合并会话写入，增加历史草稿恢复、可配置自动保存及外部变化提示。
- 支持内部标题和本地文档导航、快速打开及搜索结果定位。
- 增加代码块高亮、自动配对、预览专注和打字机模式及连续块编辑。
- 增加图片插入、截图粘贴、资源复制和文档图片根目录配置。
- 增加安全文件操作、PDF 排版配置、EPUB/LaTeX 导出和 Pandoc 导入。
- 为上述流程补齐回归测试，改善真实渲染性能及覆盖率验证。

## Impact
- 影响 editor、markdown、workspace、settings、export 及 Electron 文件和会话服务。
- 保持既有 IPC 和设置兼容，新增入口不向 renderer 提供任意路径授权能力。
- 保持 CodeMirror Markdown 为唯一数据源，不引入新的富文本编辑内核。
- 当前任务完成代码与验证；实际部署后再归档，不冒充安装运行验收。

## Acceptance Criteria
- 混合代码块、嵌套列表和引用任务只修改用户选中的实际任务。
- 已授权工作区内图片在预览和各类导出中采用一致能力，导出不修改旧能力。
- 中文全词、空格、超过 400 个结果及正则捕获替换均正确。
- 持续输入仅在停止后写入快照，关闭和切换前仍立即落盘。
- 标题链接在当前文档跳转，Markdown 链接和正文搜索结果定位对应文件及行。
- 图片、文件操作、草稿选择、快速打开和导出设置具有可操作入口与错误回退。
- 设置迁移、路径越界、伪造拖放和损坏草稿均不破坏原有安全边界及内容。
