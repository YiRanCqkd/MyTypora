# 改善展示与编辑体验

## Why
用户要求继续改善展示与编辑体验。实测标题进入编辑后字号从约 34px 降至 16px，
长段落编辑框仅两行高，短格式片段的固定最小宽度遮挡后文；窄窗口工具栏占据两行。

## What Changes
- 编辑控件继承所在正文或标题的字体，随内容自动增高，预留空间保护相邻正文。
- 空白文档提供直接开始输入的入口，保持 Markdown 唯一数据源和撤销行为。
- 正文采用适合连续阅读的行宽和行距，保留缩放、明暗主题和书籍字体。
- 窄窗口收起次要工具，保持常用入口和导出可见，支持键盘关闭与恢复焦点。
- 深色状态栏的选中和悬停按钮使用主题颜色，保证可读对比度。

## Impact
- 影响 document-workspace、预览布局、工具栏、HTML 导出与交互测试。
- 沿用 CodeMirror 和现有原生权限，不增加依赖或更换编辑内核。
- 用户本次已授权继续优化上述展示和编辑流程，按验收清单实施。
