# 展示与编辑体验优化记录

日期：2026-10-10。工程：UniReadMD-WebUI。

## 本次改善

- 标题、正文、代码和行内格式编辑继承原有字体、字号、字重及行距。
- 编辑框按实际源码自动增高；长段落和多行输入预留空间，避免遮挡下一段。
- 短格式片段按实际源码宽度占位，取消或提交后清理临时尺寸。
- 多行输入及键盘移动跟随光标滚动；重新测量期间保留滚动空间，避免回顶。
- 窗口、侧栏和缩放变化后重新定位编辑框。
- 空白预览可点击开始写作，提示仅用于界面，不进入 Markdown 和 HTML 导出。
- 正文默认 16px、1.75 行距，限制最大阅读宽度为 960px，并继续支持缩放及主题。
- 窄窗口将次要文档工具收进“更多”，常用工具及导出保持可见。
  Escape 关闭菜单并恢复按钮焦点，外部点击关闭菜单。
- 深色状态栏的选中和悬停按钮沿用主题背景，修复浅色底导致的文字低对比度。
- 补查宽屏编辑期间的专注模式切换，确认行宽和键盘焦点保持稳定。

沿用 CodeMirror 数据源和现有编辑会话，保留组合输入、提交、取消和撤销结构。
没有增加运行时依赖，没有改变文件访问授权与安全策略。
