## 为什么

当前渲染页点击正文或标题后会展开 Markdown 文本框，格式标记暴露，不能保持页面内的
所见即所得体验。用户明确要求参考本机 Typora 实现工作区直接编辑。

## 变更内容

- 正文、标题、简单列表和引用在原位置直接编辑，保留加粗、斜体、链接等视觉样式。
- 支持中文组合输入、Enter 新段落、基本格式快捷键、撤销重做、保存和模式切换。
- 代码、公式、图表及暂不能可靠无损转换的复杂块保留现有块编辑入口。
- CodeMirror Markdown 继续作为唯一数据源，页面编辑作为临时输入适配器。
- 编辑期间保留活动块 DOM 与浏览器选区，结束编辑后统一重新渲染。
- 图片比例、右键插入、工具栏可见性和 1.1.0 版本配置继续保留。

## 影响

- 受影响规范：document-workspace。
- 受影响模块：预览编辑会话、渲染更新策略、剪贴板与快捷键、保存及撤销链路。
- 不增加编辑器框架，不使用第三方富文本内核，不放宽 HTML 清洗与权限。
- 本阶段验收以常用文本块为范围；复杂块继续使用既有编辑方式，不承诺完整复制 Typora。
