## 设计

通过原 DOM contenteditable 临时编辑普通段落、标题、简单列表项及引用。活动会话记录
源范围、原文、最新应用内容和块前缀；安全转换行内 HTML，再通过 CodeMirror 事务写回。
活动会话期间冻结预览绑定 HTML，避免每次输入导致整个预览重建和光标跳动。

保存、导出、切换模式和离开当前块先提交活动会话；文档替换先结束旧会话。中文组合输入
结束前不写回，避免候选词丢失。撤销重做沿用 CodeMirror 历史，活动 DOM 根据源码刷新。
复杂块含图片、公式、嵌套列表或原始 HTML 时保持原入口，防止转换损失专有语义与图片尺寸。

## 验证

工具单测验证行内样式、空白、链接安全、块前缀与边界。浏览器和真实 Electron 验证点击
正文、标题样式、持续输入、中文组合、换段、格式快捷键、撤销、保存重开、右键插入和导出。
已有源码、表格、公式、Mermaid、安全和大文档流程必须继续通过。
