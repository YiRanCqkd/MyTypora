## ADDED Requirements

### Requirement: 常用文本原位可视编辑
应用 MUST 允许在渲染工作区原位置直接编辑普通正文、标题和简单列表引用，保留行内格式
视觉效果，并将变更写入 CodeMirror 单一数据源。复杂内容 MUST 保留安全的既有编辑入口。

#### Scenario: 编辑格式正文和标题
- **WHEN** 用户点击正文或标题并输入
- **THEN** 页面在当前位置展示编辑光标和原有样式，源码同步更新，保存重开保持内容

#### Scenario: 输入法、撤销和换段
- **WHEN** 用户组合输入中文、换段、应用基本格式或撤销
- **THEN** 组合输入不被提前提交，光标保持可用，操作可通过统一历史撤销重做

#### Scenario: 避免复杂块转换丢失
- **WHEN** 用户编辑含图片尺寸、公式、嵌套结构或原始 HTML 的复杂块
- **THEN** 应用沿用已有块编辑入口，保留源码语义与安全边界
