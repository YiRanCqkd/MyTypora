# 扩展 Typora 写作流程

## Why
用户已确认按上轮建议顺序优化。本次在现有 Markdown 唯一数据源和原生授权架构中，
逐步改善行内编辑、统计、公式、图片整理、导出和主题，并解决已测得的大文档瓶颈。

## What Changes
- 常见行内格式只展开对应源码片段，复杂块继续采用现有块编辑。
- 源码、预览和编辑框支持选区统计，支持统计单位和阅读速度设置。
- 增加化学公式、文档内公式编号与引用，保留现有公式输入兼容。
- 增加已授权本地图片的批量整理，不删除可能被其他文档使用的原图。
- 补充固定格式的高级导出与配置，保持命令参数白名单。
- 增加可选写作主题、明暗主题分别设置，继续兼容自定义 CSS。
- 纯正文大文档缓存渲染；图表按可见区域加载，导出等待全部图表。

## Impact
- 影响 document-workspace、Markdown 渲染、原生图片和导出服务及设置界面。
- 不更换富文本内核，不放宽 CSP、路径授权或测试门槛。
- 本次是具体增量优化；云图床、任意外部命令和全部第三方主题兼容仍需独立设计。
