# 写作流程优化记录

## 本次实现

1. 点击加粗、斜体、行内代码或链接时，仅展开相应源码片段；支持实时写回、
   取消和撤销，相邻正文继续渲染。复杂块沿用块编辑。
2. 源码、预览与预览编辑框支持选区统计。点击底部字数可选择字数或字符数，
   设置阅读速度及公式自动编号。
3. 支持文档内公式编号、手动编号、前向引用及可点击引用；支持化学公式与文档内宏。
   不允许公式启用任意 HTML 或脚本信任。
4. 工具栏增加紧凑的“整理图片”入口。将已授权本地图片复制到工作区内唯一目录，
   更新 Markdown 引用，保留原图。缺失图片或越界时停止，文档变更可撤销。
   整理后需保存文档；没有自动删除可能被其他文档引用的原图。
5. 增加 RevealJS、MediaWiki、reStructuredText、Textile、OPML 五种固定导出格式；
   增加目录层级、EPUB 章节级别和固定配置预设。需要 Pandoc 3.10。
   OPML 输出完整 XML 文档；外链图片使用产物旁持久目录。
6. 增加白纸、书籍、暖纸、石墨、午夜五种写作主题，明暗配置独立保存，跟随系统切换，
   HTML 导出保留所选写作主题。继续提供原有自定义 CSS 通道。
7. 超过约一百万字符的受支持纯正文使用块缓存；复杂语法回退完整解析。
   图表按可见区域及预加载范围渲染，导出等待全部图表完成。

## 回归中修正

- 选区统计在浏览器完成输入后按帧刷新，避免界面重绘覆盖尚未提交的输入。
- 移除片段格式时结束该编辑会话，避免错误隐藏同段后续相同格式。
- 输入法组合期间不以 Escape 或快捷键结束文档编辑。
- 导出移除编辑隐藏标记，避免正在编辑的正文在导出产物中消失。
- 浏览器模式保存主题选择，刷新后继续跟随系统；桌面版沿用原生设置存储。
- 图表主题变化重新渲染，异步输出过期时重新生成。
- 原生应用每次启动使用不同本地端口，写作偏好改由主进程受限配置持久化，
  浏览器存储仅作同步缓存；启动读取期间不覆盖用户已修改的设置。
- 图片整理编码路径中的井号、括号等字符，ICO 副本保持资源服务认可的扩展名。
- 修正深色大纲的固定深色文字，写作设置按钮与当前主题保持一致。

## 实际格式验证

通过真实 Pandoc 3.10 验证五种新增格式与 EPUB 章节选项，检查正文、
幻灯片结构、OPML 层级，以及外链图片副本字节和路径。
初次测试暴露 OPML 缺少完整文档包装及资源持久化，已修正后通过。
幻灯片默认依赖外部 RevealJS 库，当前没有打包成完全离线的放映文件。

## 剩余差异

本次是增量优化，尚未达到完整 Typora 等价：完整 MathJax／physics 宏、
RTF 剪贴板解析、云图床上传、任意自定义导出命令及模板体系、
全部第三方 Typora 主题包兼容仍有差异。纯正文缓存不覆盖复杂语法的大文档，
也没有将编辑器整体替换为完整富文本编辑内核。

全前端 90% 覆盖率、旧 Node 渲染性能门禁须按实际结果单独报告，
不能由局部核心覆盖率或浏览器功能测试代替。
完整人工安装向导、原生文件对话框、真实系统拖放及用户生产部署仍待人工验收，
第 9 项任务保持未完成，变更暂不归档。
