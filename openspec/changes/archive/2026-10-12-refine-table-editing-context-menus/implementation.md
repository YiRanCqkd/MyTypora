# 实施记录

## 需求依据与实现

用户明确反馈表格仍有独立输入框，并要求参照本机 Typora 调整右键菜单。本次按该范围补充
既有原位可视编辑，不变更应用版本，也不替换编辑器内核。

普通表格单元格复用可视编辑会话，直接使用原 DOM 接收输入；通过表格解析、序列化写回
CodeMirror。保留行内格式、列对齐、竖线转义、中文组合输入、导航、行列快捷键及历史记录。
无属性的 br 可作为单元格内换行重复编辑；图片、公式及其他复杂 HTML 保留源码入口。

工作区菜单共享紧凑样式和定位工具。先隐藏测量再显示，随后聚焦首个可用命令，避免尚未
可见时聚焦失败。表格右键先提交原位编辑，等待预览刷新后再设置选区并打开菜单，防止
刷新清理误关新菜单或清空结构操作所需的选区。

菜单尺寸与样式只读参考本机 Typora 1.2.4 的样式资源，没有修改其安装文件或加载其脚本。
