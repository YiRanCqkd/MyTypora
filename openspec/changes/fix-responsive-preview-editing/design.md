# 设计

正文不再按固定像素宽度封顶，改为占满工作区并保留现有响应式内边距。
源码和专注视图沿用相同规则，不缩放工具栏或侧栏。

编辑容器使用 ResizeObserver 监听真实尺寸，按动画帧合并测量；卸载或换容器时清理。
重新定位不重建编辑会话，不改变内容、选区或撤销边界。仅主动调整尺寸时保证光标可见，
普通滚动不强制回到光标。

输入写回后，v-html 替换旧节点会短暂丢失占位高度。因此在 DOM 更新前临时保留滚动空间，
重新建立编辑占位后恢复原内边距和滚动位置，再检查活动光标。清理操作幂等；新一轮渲染
取消上一轮异步布局，避免旧结果覆盖最新内容。普通布局测量复用同一滚动保护函数。

文本选区的活动端按 selectionDirection 确定：正向使用 selectionEnd，反向使用
selectionStart。全局滚轮处理作为唯一入口，普通滚动与 Ctrl 缩放分别处理。
滚动后浮层的响应式样式可能尚未提交，光标镜像测量使用正文锚点的实时位置，
避免读取上一帧浮层坐标；输入高度由统一布局模块维护。

保留类型、代码检查、单元及浏览器门槛，新增用例先对上一版静态产物复现问题。
使用独立安装包目录进行原生和静默安装、卸载验证；人工部署前不归档。
