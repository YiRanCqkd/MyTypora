## 为什么

当前预览图片不能通过右键调整显示大小，需要编辑源码。用户要求提供比例设置，并将本轮
版本统一更新为 1.1.0。

## 变更内容

- 图片右键提供原图尺寸的 25%、50%、75%、100%、150%、200% 和自定义比例。
- 自定义比例范围为 1%～400%，始终保持纵横比，并提供恢复自动大小。
- 将尺寸写入当前图片的 HTML 标签，支持撤销、保存重开和内建 HTML 导出。
- 百分比以图片原始像素宽度为基准；图片始终受当前内容区宽度约束，避免横向溢出。
- 应用、前端、锁文件、Windows 文件资源及安装包版本统一为 1.1.0。
- 按用户补充要求，顶部快捷操作栏和左下角偏好设置默认隐藏；视图菜单提供两个独立开关，
  状态持久化并同步菜单勾选与已打开窗口。
- 源码模式改为可取消的圆形选择控件，侧栏开关在源码与渲染模式下始终可见。
- 参照本机 Typora 1.2.4 的中文菜单及样式资源，增加工作区空白右键插入菜单，支持标题、
  指定行列表格、本地图片、段落、代码块、公式块、引用、列表、任务和水平分割线。

## 审查记录

- 用户已明确回复“按该方案实现”，批准图片缩放方案。
- 用户后续明确要求两个区域默认隐藏并可通过视图菜单分别显示和隐藏，作为本轮追加范围。

## 影响

- 受影响规范：document-workspace。
- 受影响模块：图片源定位、预览右键菜单、Markdown 单源编辑、发布版本配置。
- 不修改图片文件本身。普通 Markdown 图片首次设置尺寸时转换为兼容 HTML 图片标签。
- 不覆盖历史发布产物；新增独立 1.1.0 安装包。
