## 设计

比例以图片 naturalWidth 为基准，生成像素宽度，height 为 auto。HTML 图片保留原有
src、alt、title 及无关属性，仅调整宽高相关属性和样式。普通 Markdown 图片转换为 HTML
图片；链接包裹的图片保留链接。通过源映射块、块内图片序号和解析后的图片列表定位目标，
只替换实际选中的图片，避免重复路径误改。无法可靠定位或图片尚未加载时给出说明。

菜单使用现有 Vue 工作台模式，支持常用比例、自定义和恢复自动，适配明暗主题及窗口边界。
文档切换、源码更新、滚动、窗口缩放、Escape、外部点击时关闭，避免过期目标写入。
修改通过 CodeMirror 单个事务完成，沿用现有保存、恢复快照、撤销及导出链路。

## 验证

单元测试覆盖重复路径、引用图片、链接图片、中文及特殊字符、HTML 属性保留、非法比例。
浏览器测试覆盖菜单、实际尺寸、纵横比、自定义校验、撤销、会话重载、导出和关闭行为。
发布测试检查 package 版本、Windows 资源、真实 Electron 冒烟和独立 NSIS 产物。
