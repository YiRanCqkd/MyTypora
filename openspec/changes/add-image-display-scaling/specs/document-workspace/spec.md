## ADDED Requirements

### Requirement: 图片显示比例
应用 MUST 允许在预览图片上右键设置原图宽度的常用比例、自定义 1%～400% 比例和自动大小，
保持纵横比并避免超出内容区。尺寸修改 MUST 写入 Markdown 单一数据源。

#### Scenario: 设置并持久化图片比例
- **WHEN** 用户右键选择一张已加载图片并设置 50%
- **THEN** 仅该图片按原始宽度的一半显示，修改可撤销，保存重开及内建 HTML 导出保持尺寸

#### Scenario: 自定义比例校验及恢复自动
- **WHEN** 用户输入非法比例或对图片选择恢复自动大小
- **THEN** 非法输入不修改文档，恢复自动移除该图片尺寸限制并保留图片内容和链接

#### Scenario: 防止目标过期
- **WHEN** 菜单开启后文档发生变化、切换或预览滚动
- **THEN** 菜单关闭且不能继续修改旧图片目标

### Requirement: 简洁工作区显示设置
应用 MUST 默认隐藏顶部快捷操作栏和左下角偏好设置，在视图菜单中提供独立显示开关，
记住用户选择并保持菜单勾选与窗口显示一致。

#### Scenario: 首次启动工作区
- **WHEN** 用户未设置过区域可见性
- **THEN** 两个区域均隐藏，视图菜单两个显示选项均不勾选

#### Scenario: 独立切换并重启
- **WHEN** 用户通过视图菜单显示快捷操作栏，保持偏好设置隐藏，并重启应用
- **THEN** 快捷操作栏仍显示，偏好设置仍隐藏，两个菜单勾选状态分别匹配

### Requirement: 源码模式与侧栏独立切换
应用 MUST 提供可取消的圆形源码模式选择控件，选中时显示源码，取消时显示渲染效果。
显示侧栏和隐藏侧栏开关 MUST 在两种模式下均可见，切换源码模式不得改变侧栏显示状态。

#### Scenario: 切换源码模式并独立操作侧栏
- **WHEN** 用户选中或取消源码模式，并点击显示侧栏或隐藏侧栏
- **THEN** 内容区按选择展示，侧栏仅根据其自己的开关显示或隐藏，两个入口始终可用

### Requirement: 工作区右键插入
应用 MUST 在渲染工作区空白处提供右键插入菜单，包含标题、表格、图片及常用 Markdown 块，
按点击位置插入而不覆盖现有正文，插入支持撤销，并保留图片和表格各自的右键菜单。

#### Scenario: 从空白处插入内容
- **WHEN** 用户右键选择标题、指定行列表格或本地图片
- **THEN** 生成对应内容，标题和表格进入编辑状态，文档原有内容保持完整
